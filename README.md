# Changes in the scope and intent of US state legislation on ivermectin and pharmacy dispensing trends, 2020–2026

This repository contains the following code: 
1. Regression analyses examining the association between monthly state-level ivermectin dispensing rates 
from 2019 to 2023 and legislative trends
2. Figures characterizing temporal changes in ivermectin-related legislation between 2020-2026 in the U.S.
